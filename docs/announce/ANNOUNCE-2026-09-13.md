# Announcement draft — v2026.09.13-rc3

One paragraph, for a community post. Every figure in it is a cell on
[`bench/LEADERBOARD.md`](../../bench/LEADERBOARD.md); nothing that is not on that page appears here.

---

**PXA v2026.09.13-rc3 is up.** The headline is speculation: on every card family from Pascal up the automatic decode
default is now a long n-gram stage on its own instead of the n-gram → trained-head cascade, and on a
two-card V100 pair, in one bracket against mainline `llama.cpp` at its current head and at its own best
speculation, it takes all three decode classes — **+18% on a synthetic repetitive prompt, +27% on a
real repetitive workload, and +69% on free prose** — with the drafter proven not to change the output,
only the rate. Prefill on the same pair leads by **+18% / +49% / +3% / +1%** at 512 / 3,121 / 8,192 /
20,801 prompt tokens. On four P100s the same table stage, armed on its own, reads **+107%** on the
synthetic control class (the speculation ceiling), prefill runs **+121% / +58%** at 3,121 / 20,801 tokens, and free prose is **+174%**
ahead of both mainline and upstream `ik_llama.cpp`. Dense **Gemma 4 is supported** this release — its
wide attention layers now run on the card instead of being placed on the CPU backend — and
**GLM-5.3-Flash runs as a beta**, on six cards and on all seven, with its limits written down rather
than discovered later (one slot per server among them). At two concurrent clients on the same pair it leads all three classes as well — **+24% on the
synthetic control, +25% on the real repetitive workload, +138% on prose** — after a fix that this
release owes to its own gate: the shipped default could run out of memory at two slots on 16 GB
cards, and the budget that sizes speculation now prices every slot and keeps only the reserve it
was measured to need. Two things it does *not* claim: run this engine on mainline's own `Q4_K_S`
file on four P100s and **mainline's prefill is faster** — 7.2% at 3,121 tokens and 54.2% at 20,801 —
on the board in full rather than left out; and speculative output is not byte-reproducible at
temperature 0 on any engine, so speculative builds are gated on fidelity rather than on a checksum.
The board marks every open cell and says what is being tried on
it, and `docs/NEXT-RELEASE.md` lists what this cut deliberately did not do. Optimisation continues in
the next release.
