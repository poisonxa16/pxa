# Report a problem (4.0)

A crash, a wrong answer, or a speed below the release notes table is exactly what a report is for.

Use Control's **Report a problem**, or write in the PXA Discord **#support** channel. On a beta build, say **beta** and the version. Name the card, the model file, and the command, or just send the Control report.

Discord: <https://discord.pxanetwork.com>

The speeds to compare with are the table in the 4.0 release notes and the lines in the [model quick start](MODEL-QUICKSTART-4.0.md). On the beta channel, **Install update**, then **Release notes**, shows the notes for the build you installed.

## From Control

**Help**, then **Report a problem**.

You see the exact text that would be sent, and nothing else. Home paths, host names, addresses, user names, and anything that looks like a key are already removed. You can edit the text. Nothing is sent until you press **Send**.

- **About which server** picks the model server the report is about.
- **Contact** is optional. A Discord name is enough for a reply to find you.
- **Send** files the report. On success the page shows a report id. Quote that id if you write to us again.
- **Copy report** copies the same text. The page tells you to paste it into **#support** on the PXA Network Discord. Use that when Send cannot reach us. The page says so if Send fails.

Do not paste a sign-in address into the report or into chat. The report already leaves those out. If you build the report while Control is not answering, the page says the log lines in that copy are not redacted: read them before you send.

## From Discord

In **#support**, include:

1. The version (and the word **beta** on a beta build).
2. The card (name and how many).
3. The model file name.
4. The command you ran, or the buttons you pressed in Control (Home **Start**, Launch **Show plan**, and so on).
5. What you expected and what you got. For a low speed, say the number you saw and the row you compared it with.

A Control report covers those on its own. You can still paste it into **#support** and add the word beta.

## Coins for a confirmed report

A confirmed report can add coins to your wallet. That is a supporter reward for helping. Open **Store**, **PXA Coins**, press **Get a report code**, and paste the code with the report so it is tied to your wallet. The code works once, for 7 days. **Ways to earn** on the wallet shows the current amounts, including a beta test report.
