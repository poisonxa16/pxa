Available from PXA 

    
Published at huggingface.co/poisonxa. A download goes straight into the first model folder above: it picks up where it stopped, keeps only a file whose sha256 matches the one the repository publishes, fetches every part of a split model, and puts the .expert-counts.csv next to the gguf. The model file is not otherwise touched.

    

      

      

      

    

    

      
      
      
    

    

      Supporter models: your Hugging Face key
      
Models the community supports live in a repository that only a key can read. Paste a Hugging Face token with access to it. It is kept on this machine beside the other Control settings (readable by your user alone) and sent to huggingface.co and nowhere else; it never comes back to this page and is never written to a log.

Expert map

    
For a mixture-of-experts model that does not fit on the card. Rebuild starts from the map shipped with the model. Further passes stop when the speed stops rising. The fastest map is kept. The model file is not changed.
